Method · {{ rows.0.method }}

How the score is made

  1. 01 · Raw

    Each judge's marks are combined by the rubric's weights into one score from {{ rubric.scale_min }} to {{ rubric.scale_max }}. The raw mean is the plain average of a project's reviews.

  2. 02 · Judges set true

    How lenient each judge is, is measured against what the other judges gave the same projects, and taken off their scores. A judge who drew strong projects is not mistaken for a generous one. The fewer reviews a judge gave, the less of their leniency is believed.{% if facts.flat %} {{ facts.flat }} judge{{ facts.flat|pluralize }} gave every project the same score; those scores count as no opinion.{% endif %}

  3. 03 · Adjusted

    Projects here received between {{ facts.fewest }} and {{ facts.most }} reviews. {% if jury_k %}A project is pulled toward the panel mean as if {{ jury_k|floatformat:"-1" }} more reviews at that mean had been given, so a score resting on two reviews is trusted less than one resting on five.{% else %}The organizers have switched the jury-size adjustment off for this event.{% endif %} This is the score that ranks.

Community votes, where an event has them, are shown beside the judged score and never mixed into it.
